# OCRX
 Translate PDFs and images with ease using OCRX - Foorsa Translations. This web app leverages OCR technologies and the OpenAI GPT-3 API to accurately translate various documents, including certificates and degrees. Join us in breaking language barriers!

## Template generation health

The API exposes `/api/v1/health/templates` to verify that Google Apps Script is reachable and authorized. Use `/api/v1/health/templates?deep=1` as a canary check when you need to prove a real Google Docs template can be copied and returned as document/PDF links.
